# CTR Toolkit Documentation

Welcome to the official documentation for the **Blender CTR Toolkit**.

## Modules

- [Navigator Module](user-guide/navigator.md) – Detect, select, and duplicate quadblocks and triblocks.
- [Validator Module](user-guide/validator.md) – Validate mesh objects and vertex groups for issues.
- [Render Module](user-guide/render.md) – PS1‑style rendering with blend modes and vertex snap.
- [Range Box Module](user-guide/range_box.md) – Visual 1000‑unit boundary reference.
- [Material Manager](user-guide/material_manager.md) – Handle constant materials and texture remapping.
- [Item List Module](user-guide/qb_tb_list.md) – Interactive checklist for blocks, navigation points, and groups.
- [QB/TB Export Module](user-guide/qb_tb_export.md) – OBJ export with filtering, textures, and duplicate processing.
- [Help Utilities](user-guide/help_utils.md) – Quick access to docs, tutorials, issue tracker, and keymaps.
- [Addon Updater](user-guide/addon_updater.md) – Automatic update checks and installation.
- [Keymaps](user-guide/keymaps.md) – Default shortcuts and customisation guide.
