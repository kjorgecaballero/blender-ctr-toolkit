# Help Utilities – User Guide

The **Help Utilities** module provides quick access to documentation, tutorials, issue reporting, keymap reference, and update notifications. All help buttons are located in the **CTR panel header** (right side) in the 3D Viewport sidebar.

---

## Available Help Buttons

| Name          | Action                                                        |
| ------------- | ------------------------------------------------------------- |
| Documentation | Opens the online documentation in your default browser.       |
| Tutorials     | Opens a YouTube playlist with video tutorials.                |
| Report Issue  | Opens the GitHub issue tracker with pre filled templates.     |
| Keymaps       | Shows a popup with default keyboard shortcuts.                |
| Update        | Checks for addon updates (appears red if an update is ready). |

> The update button is integrated with the Addon Updater module – see its separate guide for details.

---

## How to Use

1. Open the 3D Viewport Sidebar (press `N`).
2. Go to the **CTR** tab.
3. Look at the top right corner of the panel – the help buttons are aligned there.

### Documentation Button

- Opens the CTR Toolkit GitHub pages site.
- Use this to read installation instructions, troubleshooting, and advanced guides.

### Tutorials Button

- Opens a YouTube playlist maintained by the developer.
- Covers visual user guides and tutorials.

### Report Issue Button

- Opens GitHub's "New Issue" page with templates for Bug Report and Feature Request.
- Fill out the form to help the developer reproduce and fix problems.

### Keymaps Button

- Displays a popup listing the default keyboard shortcuts (Ctrl+Shift+E, Ctrl+L, Ctrl+Shift+D, Ctrl+Shift+S).
- Also tells you where to change them (Edit -> Preferences -> Keymap).

### Update Button

- Shows a notification if a new version is available.
- Click to open the update popup and install the latest version.
- The button turns red when an update is ready.

---

## Customisation

- The help buttons are part of the main CTR panel and cannot be removed.
- You can hide the entire CTR panel by collapsing the sidebar or disabling the addon.
